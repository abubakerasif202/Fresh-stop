# Product image rights register

Audit scope: released enquiry catalogue (171 products, 11 categories). This register covers the 12 branded entries that used the shared placeholder before the owner-requested illustration update and the 10 baseline product-photo paths included in the public range (the mixed box is excluded from that range). It records evidence present in this checkout; a file, URL, image appearance, or generic brand identity alone does not establish permission.

## Generated illustration approval and limits

The owner requested images for the missing packs and explicitly selected “Generate labelled food illustrations.” Twelve original gouache-style illustrations were generated using the built-in image tool and optimized to 1000px WebP (831,466 bytes combined). They contain no logos, brands or packaging. The combo entry uses abstract folded shapes rather than invented box contents; the spice entry uses an abstract powder swirl rather than asserting a blend. Other entries depict generic foods, without SKU/weight/origin/ingredient/stock claims. Decorative foliage is visual decoration, not an ingredient claim.

All originals remain in excluded local `assets/product-masters/`; the public optimized outputs and SHA-256 records are in the evidence manifest. Cards and details disclose AI provenance and that branded packaging is not shown. Database images are substituted only while the exact approved slug still references the shared placeholder; a future actual image takes precedence automatically. No Product rows or other database records were edited. Real verified packshots for all 12 remain an optional content improvement, not a claim established by these illustrations.
