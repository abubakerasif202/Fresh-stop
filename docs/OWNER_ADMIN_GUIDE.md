# Owner admin guide (summary)

Full detail: [ADMIN_GUIDE.md](ADMIN_GUIDE.md). Open `/admin` and sign in with the admin credentials held in Vercel (never share them in chat).

- **Products:** edit name, description, category, image, unit, price; approve price and GST category; set stock or the Backorder policy; unpublish instead of deleting.
- **Orders:** view payment and fulfilment status; payment exceptions are listed separately — never mark an order paid manually.
- **Delivery:** zones, postcodes, fees, minimums, pickup branches.
- **Pause selling:** turn off paid checkout in admin settings.
- **Prices:** only owner-approved prices are payable; estimates are never charged.
